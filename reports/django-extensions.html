Приложение: воспроизводимость

Запуск

python -m projectpulse index --repo <путь> --mode full
python -m projectpulse index --repo <путь> --mode incremental
python -m projectpulse report --repo <путь> --format html --out report.html

Метрики считаются относительно даты HEAD-коммита, а не текущего времени, поэтому повторный импорт не меняет значения.

Багфиксы определяются по регулярному выражению из порогов; владение считается по изменённым строкам.
