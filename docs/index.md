# ProjectPulse

ProjectPulse - локальная система цифрового двойника программного проекта. Она читает Git-историю, строит модель кода и зависимостей, считает метрики, находит риски, показывает динамику и формирует отчёт с рекомендациями.

Система работает без сети после клонирования репозиториев, не требует прав администратора и не использует внешние анализаторы кода. Все алгоритмы метрик, графов и статистики реализованы в проекте.

## Что умеет система

- Импортирует локальный Git-репозиторий в SQLite: коммиты, изменения файлов, сущности Python, импорты, ссылки.
- Поддерживает полный импорт, инкрементальное обновление и пересборку с нуля.
- Строит две проекции зависимостей: файлы и сущности кода.
- Хранит версии срезов графа для HEAD, тегов и веток.
- Считает 10 метрик: 5 классических, 3 собственные и 2 временных ряда.
- Применяет 10 правил риска, 4 из них основаны на трендах.
- Вычисляет индекс здоровья проекта от 0 до 100 и объясняет вклад компонентов.
- Показывает дашборд, временную шкалу, навигацию по графу и сравнение двух проектов.
- Формирует автономный HTML и PDF с разделами "Сводка / Риски / Динамика / Граф / Рекомендации".
- Проводит мини-исследование связи churn и владения кодом с будущими багфиксами.
- Расширяется плагинами метрик и правил без изменения ядра.

## Быстрый старт

Требования: Python 3.11 или новее, Git в PATH. Для PDF нужен reportlab, для property-тестов - hypothesis. Обе зависимости необязательны для основного сценария.

```powershell
cd C:\Users\sound\projectpulse
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[pdf,test]"
```

Демонстрационные репозитории фиксируются на конкретных коммитах:

```powershell
python scripts\prepare_samples.py
```

Пример работы через командную строку:

```powershell
python -m projectpulse index --repo samples\pluggy --mode full
python -m projectpulse report --repo pluggy --format html,pdf --out reports
python -m projectpulse compare --a pluggy --b django-extensions
python -m projectpulse research --healthy samples\pluggy --problematic samples\django-extensions
```

Запуск графического интерфейса:

```powershell
$env:PROJECTPULSE_HOME = "C:\Users\sound\projectpulse\demo_home"
python -m projectpulse gui
```

Полный демонстрационный прогон, включая отчёты, сравнение, исследование и замеры:

```powershell
$env:PYTHONPATH = "C:\Users\sound\projectpulse\src;C:\Users\sound\projectpulse"
python scripts\run_all.py --reindex --bench --tests
```

## Структура проекта

```text
projectpulse/
  src/projectpulse/
    analysis/        метрики, правила, графы, статистика, исследование
    core/            конфигурация, события, плагины, сборка runtime
    gitio/           обёртка над git CLI
    indexer/         полный, инкрементальный и rebuild-импорт
    report/          сборка данных, HTML и PDF
    storage/         SQLite-схема и слой запросов
    ui/              Tkinter-интерфейс на семь экранов
  plugins/           пример плагина
  scripts/           подготовка данных, замеры, профиль, полный прогон
  tests/             106 тестов unittest и hypothesis
  docs/              проектная документация
  repos.json         зафиксированные демонстрационные репозитории
  reports/           готовые отчёты и результаты замеров
```

## Ограничения

- Анализируется Python-код. Другие языки не входят в текущую модель.
- Багфикс определяется по регулярному выражению в сообщении коммита, поэтому возможны пропуски и ложные срабатывания.
- Владение считается по изменённым строкам, а не по экспертизе автора.
- Корреляции в мини-исследовании не доказывают причинность.
- Графовые алгоритмы реализованы вручную. Сторонние графовые библиотеки не используются.
